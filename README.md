# ArtimaDev | Estudio de Ingeniería Android

Repositorio oficial de la página web de **ArtimaDev**, estudio de desarrollo independiente con base en Horta, Barcelona. 

Este sitio web sirve como portafolio principal para nuestra suite de aplicaciones nativas de Android y aloja la documentación legal requerida por Google Play Console.

## 🚀 Proyectos Principales

*   **Motorpedia Pro:** Herramienta profesional de diagnóstico automotriz (OBD2 y UDS) vía Bluetooth. Lectura de telemetría en vivo, borrado de códigos DTC y análisis avanzado de sondas.
*   **CineMatch:** Recomendador inteligente de streaming con filtrado cruzado en 12 plataformas, candado parental certificado por TMDB y modo de vinculación en pareja.

## 📂 Estructura del Sitio

El sitio está construido con **HTML5** y **Tailwind CSS** para garantizar la máxima velocidad de carga y adaptabilidad móvil. Consta de cuatro documentos principales:

*   `index.html`: Portada corporativa, filosofía del estudio y acceso rápido a los proyectos.
*   `motorpedia.html`: Ficha técnica de la aplicación de diagnosis, incluyendo un buscador web integrado de códigos de avería (DTC).
*   `cinematch.html`: Resumen de características del recomendador de entretenimiento.
*   `privacidad.html`: Política de privacidad y gestión de datos de usuario (documento legal indispensable para el cumplimiento normativo en Google Play).

## 🛠️ Stack Tecnológico

*   HTML5
*   Tailwind CSS (vía CDN)
*   Vanilla JavaScript
*   Alojado en GitHub Pages
